# Library Management System

## Project Description

This project is a simple library management made with Python. It lets the users add books, list all books, search for a book, and exit program.

## Files

- 'book.py' contains the Book class.
- 'library_manager.py' contains the main program and menu

## Features

- Add a new book
- List all books
- Find a book and title or author
- Exit the program

## How to Run

1. Make sure Python is installed.
2. Keep 'book.py' and 'library_manager.py' in the same folder.
3. Run 'library_manager.py'
4. Choose an option from the menu.
